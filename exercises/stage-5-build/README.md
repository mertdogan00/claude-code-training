# Stage 5: build something real

On stage, the room votes for ONE of these. At home, do all three: each teaches a different
muscle. Every scenario has its ready starter prompt in `../../prompts/`.

## Scenario 1: write your own skill

Turn a chore YOU repeat into a skill (like the pdf-summarizer you installed). Recipe:
describe the chore to Claude Code and ask it to draft the `SKILL.md`; refine the wording;
install; run. You never write code: you write INSTRUCTIONS.

## Scenario 2: connect a real integration

Take the plugin/MCP path from Stage 4 and wire it into a task: "her sabah şu klasördeki yeni
dosyaları özetle", "şu servisten veriyi çek, tabloya dök". The value appears when a tool call
sits INSIDE a real routine.

## Scenario 3: from idea to output

One sitting, one product: a single-page site, a working form, a small report generator.
Start from `../../prompts/scenario-3.md`, speak Turkish, iterate ("daha büyük", "rengi
değiştir", "harika, devam").

## The rule that matters

Whichever you pick: start SMALL, verify every step, and let `CLAUDE.md` carry the rules you
find yourself repeating.
