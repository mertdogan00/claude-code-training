Open Claude Code in `exercises/stage-5-build/` and paste:

> Tarayıcıda oynanan küçük bir refleks oyunu yapalım: ekranda beliren hedefe tıkla, puan
> topla, süre bitince skor tablosu göster. Yapı şöyle olsun: index.html + style.css +
> game.js ön yüz, minik bir Node.js sunucusu, skorlar SQLite'ta dursun. Basit ama modüler
> yaz; npm run dev ile çalışsın. Önce planını üç maddeyle söyle, onaylayınca başla.

> Hedef gitgide küçülsün. · En yüksek 5 skoru isimle kaydet. · Bir de "tekrar oyna" butonu.

The point is not the game: it is watching an idea become a RUNNING thing while you only
spoke Turkish.
