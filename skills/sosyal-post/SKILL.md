# Sosyal Post

When invoked with a source text (pasted or a file path):

1. Extract the ONE core message first; state it back in a single line.
2. Produce three versions, each clearly labeled:
   - **LinkedIn:** 4-6 short paragraphs, hook first line, no hashtags spam (max 3), a closing
     question.
   - **Instagram:** 2-3 sentences + line breaks, warmer tone, 5 hashtags on the last line.
   - **X:** max 280 characters, punchiest angle, no hashtags.
3. All Turkish; keep the user's facts exactly, invent nothing; no emoji unless the source has
   an informal tone.
4. End with: "Hangisini açalım?" so the user picks one to refine.
